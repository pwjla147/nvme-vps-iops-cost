## NVMe 和普通 SSD VPS 差在哪

差距集中在三个数字上：顺序读写带宽、随机 IOPS、延迟。

物理层面，NVMe 的顺序读写能做到 4–6 GB/s，SATA SSD 卡在 500–600 MB/s，差 8–10 倍；随机 IOPS 一个是 50 万以上，一个是 8–10 万；延迟从几十微秒降到 10–30 微秒。翻译成实际体验，就是 Docker 拉镜像快 2–3 倍，git clone 少花四到六成时间，MySQL 查询和 PHP 冷启动明显变快。

但要补一句：这些是物理盘的上限。VPS 是共享环境，你能分到多少，取决于商家有没有超售。同一张「NVMe」标签下面，实测差距可以拉到十几倍，后面有具体数据。

## 下单前，花五分钟自己跑一次 fio

用小时计费开一台测试机，一条命令就能验证商家的宣传是真是假。

多数 NVMe 商家支持按小时计费，开机、测完、销毁，成本几乎为零。命令用这条：


fio --rw=randread --bs=4k --iodepth=32 --numjobs=4 --runtime=300 --time_based --direct=1


跑的时候注意三点：随机读、随机写和 70/30 混合各测一轮，模拟真实数据库流量；同一台机器多跑几次取中位数，单次结果会被邻居干扰；最后看 p99 延迟，别只看平均值。流量也别忘了对一下，盘快但流量按超出部分计费，瓶颈只会换个地方出现。

## 常见问题

**NVMe VPS 一定比 SSD VPS 快吗？**
不一定。带宽和延迟确实高一个量级，但只有随机读写密集的应用吃得到，静态站和轻量服务两者跑起来基本一样。

**预算 $5/月 以内能买到真 NVMe 吗？**
能。UpCloud $5 档实测 100,000+ IOPS，Hetzner CX22 约 $5，KnownHost $5 也是全线 NVMe。判断标准是实测 4K 随机读不低于 15,000 IOPS，低于这个数的要警惕。

**为什么同一家 VPS，不同人测出的 IOPS 差很多？**
两个原因：测试参数不同，队列深度和并发数会成倍影响结果；以及超售，同一台物理机上邻居跑满磁盘时，你的 p99 会先崩。所以看数据要同时看平均值和 p99。

**RackNerd 的 SSD 会拖慢我的网站吗？**
静态站、低流量博客、备份这类负载不会，它省下的正是你用不到的磁盘性能。真上了数据库再换 NVMe 也不迟。
